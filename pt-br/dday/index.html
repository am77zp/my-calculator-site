Calculadora de Contagem Regressiva

Calcula os dias restantes (ou passados) entre uma data inicial e uma data alvo.

Como usar

  1. Digite uma data inicial, ou deixe em branco para usar hoje.
  2. Digite a data alvo da contagem regressiva.
  3. Clique em "Calcular" para ver o resultado.

Como funciona

A calculadora encontra o número de dias corridos entre a data inicial e a data alvo. Se o alvo for no futuro, você verá uma contagem "D-"; se já passou, uma contagem "D+".

Exemplos

Data inicial hoje, data alvo em 10 dias → Resultado: "D-10"
Data inicial hoje, data alvo há 5 dias → Resultado: "D+5"

Perguntas frequentes

O que acontece se a data inicial e a alvo forem iguais?

Aparecerá "Hoje é o D-Day".

Posso usar uma data alvo passada?

Sim, a calculadora mostrará quantos dias se passaram desde essa data.
