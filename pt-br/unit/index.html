Conversor de Unidades

Converte entre unidades de comprimento, peso e volume.

Como usar

  1. Escolha uma categoria: comprimento, peso ou volume.
  2. Digite o valor e escolha as unidades de origem e destino.
  3. Clique em "Converter" para ver o resultado.

Como funciona

Cada unidade é primeiro convertida para uma unidade base comum (metro, quilograma, litro), depois convertida para a unidade de destino.

Exemplos

100 cm → = 1 m
10 lb → ≈ 4,53592 kg

Perguntas frequentes

Quais unidades são suportadas?

Comprimento: mm, cm, m, km, in, ft, mi. Peso: mg, g, kg, t, lb, oz. Volume: ml, l, gal, cup.

Qual a precisão dos resultados?

Os resultados são mostrados com até 6 casas decimais.
