Über diese Seite

Eine kostenlose Sammlung alltäglicher Rechner, die direkt im Browser laufen — keine App-Installation, kein Konto nötig. Ihre Eingaben werden nie an einen Server gesendet; alles wird auf Ihrem eigenen Gerät berechnet.

Beliebte Rechner

  • Alter — Ihr genaues Alter anhand des Geburtsdatums berechnen
  • Countdown — Die Tage bis zu einem wichtigen Datum zählen
  • Rabatt — Verkaufspreis und Ersparnis berechnen
  • Einheiten — Längen-, Gewichts- und Volumeneinheiten umrechnen
  • BMI — Body-Mass-Index und Kategorie prüfen
Diese Website bietet keine Kontoerstellung, Kommentare, Chat oder persönlichen Support — nur kostenlose Rechner, die jeder sofort nutzen kann.
