Calculadora de Porcentajes

Elige el modo de cálculo e introduce el Valor A y el Valor B para obtener el resultado en porcentaje al instante.

Cómo usarla

  1. Elige el modo de cálculo (hallar la razón, la parte o el total).
  2. Introduce el Valor A y el Valor B.
  3. Pulsa "Calcular" para ver el resultado al instante.

Cómo funciona

Según el modo elegido, se usa A÷B×100 (razón), B×A÷100 (parte) o A÷(B÷100) (total).

Ejemplos

Ejemplo 1 — En el modo "¿Qué % de B es A?", con A=25 y B=200, 25 es el 12.5% de 200.
Ejemplo 2 — En el modo "¿Cuánto es A% de B?", con A=20 y B=150, el 20% de 150 es 30.

Preguntas frecuentes

¿Cuándo usar cada modo?

Usa el primero para hallar una razón, el segundo para hallar el valor real de un porcentaje, y el tercero para calcular el total a partir de una parte y su porcentaje.

¿Puedo introducir números negativos o decimales?

Sí, tanto el Valor A como el Valor B admiten números negativos y decimales.
