D-Day Calculator

Kinakalkula ang natitirang (o nakalipas) na araw sa pagitan ng starting date at target date.

Paano gamitin

  1. Maglagay ng starting date, o iwanang blangko para gamitin ang ngayon.
  2. Ilagay ang target na petsa na gusto mong bilangin.
  3. I-click ang "Kalkulahin" para makita ang resulta.

Paano ito gumagana

Kinakalkula ng calculator ang bilang ng araw sa kalendaryo sa pagitan ng starting date at target date. Kung nasa hinaharap ang target, makikita mo ang "D-" countdown; kung nakalipas na, "D+" naman.

Mga halimbawa

Starting date ngayon, target date 10 araw mula ngayon → Resulta: "D-10"
Starting date ngayon, target date 5 araw na nakalipas → Resulta: "D+5"

Mga madalas itanong

Ano ang mangyayari kung magkapareho ang starting at target date?

Makikita mo ang "Ngayon ang D-Day".

Puwede bang gumamit ng nakaraang target date?

Oo, ipapakita ng calculator kung ilang araw na ang lumipas mula sa petsang iyon.
